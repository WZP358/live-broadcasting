# Ollama 与 vLLM 部署大模型实践文档

## 第一部分：WSL2 环境准备

### 1.1 确认 WSL2 已安装并运行

打开 PowerShell 或 Windows Terminal，执行：

```powershell
wsl --list --verbose
```

确认输出中你的发行版（如 Ubuntu）的 Version 列为 `2`。

![](./image/2.png)

### 1.2 进入 WSL2 

```bash
# 进入 WSL2
wsl
```

### 1.3 确认 NVIDIA GPU 驱动（关键步骤）

在 WSL2 中执行：

```bash
nvidia-smi
```

![](./image/3.png)

### 1.4 安装 Python 和 pip

```bash
python3 --version
# 如未安装，执行：
sudo apt install python3 python3-pip -y
```

### 1.5 创建工作目录

```bash
mkdir -p ~/llm-deploy/models
cd ~/llm-deploy
```

## 第二部分：Ollama 部署大模型

### 2.1 安装 Ollama

在 WSL2 中执行以下命令安装 Ollama：

```bash
curl -fsSL https://ollama.com/install.sh | sh
```

![](./image/4.png)

### 2.2 验证安装

```bash
ollama --version
```

![](./image/5.png)

### 2.3 拉取模型

以 Qwen3.5 0.8B 模型为例（模型较小，适合大多数机器）：

```bash
ollama pull qwen3.5:0.8b
```

等待下载完成。也可选择其他模型：
- `qwen3:1.8b` - 1.8B 参数
- `llama3.2:1b` - Meta Llama 1B
- `gemma3:1b` - Google Gemma 1B

![](./image/6.png)

### 2.4 查看已下载的模型列表

```bash
ollama list
```

![](./image/7.png)

### 2.5 使用 Ollama 启动模型（命令行交互）

```bash
ollama run qwen3.5:0.8b
```

进入交互模式后，尝试输入以下内容进行对话测试：

```
你好，请用中文介绍一下你自己。
```

按 `Ctrl + D` 退出交互模式。

![](./image/8.png)

### 2.6 Ollama API 测试

Ollama 默认在 `http://localhost:11434` 提供服务。打开另一个终端，用 curl 测试 API：

#### 2.6.1 测试生成接口

```bash
$body = @{
    model  = "qwen3.5:0.8b"
    prompt = "用一句话介绍深度学习。"
    stream = $false
} | ConvertTo-Json

Invoke-RestMethod -Uri "http://localhost:11434/api/generate" -Method Post -Body $body -ContentType "application/json"
```

#### 2.6.2 测试 Chat 接口（兼容 OpenAI 格式）

```bash
curl http://localhost:11434/v1/chat/completions -H "Content-Type: application/json" -d '{
  "model": "qwen3.5:0.8b",
  "messages": [
    {"role": "user", "content": "你好，请做一下自我介绍。"}
  ]
}'

$body = @{
    model = "qwen3.5:0.8b"
    messages = @(
        @{ role = "user"; content = "你好，请做一下自我介绍。" }
    )
} | ConvertTo-Json

Invoke-RestMethod http://localhost:11434/v1/chat/completions -Method Post -Body $body -ContentType "application/json"
```

## 第三部分：vLLM 部署与项目接入

### 3.1 启动 vLLM 服务

本项目的 AI Agent 调用 OpenAI 兼容接口。vLLM 启动后只要提供 `/v1/chat/completions` 和 `/v1/models` 即可接入。

```bash
source ~/llm-deploy/myenv/bin/activate

VLLM_USE_FLASHINFER_SAMPLER=0 vllm serve ~/llm-deploy/models/Qwen1.5-1.8B \
  --served-model-name Qwen1.5-1.8B \
  --host 0.0.0.0 \
  --port 8000 \
  --gpu-memory-utilization 0.8 \
  --max-model-len 2048 \
  --trust-remote-code \
  --dtype float16
```

`--served-model-name` 必须和项目配置中的 `PULSELIVE_LLM_MODEL` 完全一致。

### 3.2 测试 vLLM Chat 接口

在 Windows PowerShell 中执行：

```powershell
$body = @{
    model = "Qwen1.5-1.8B"
    messages = @(
        @{ role = "user"; content = "请用一句话介绍你自己。" }
    )
    max_tokens = 128
} | ConvertTo-Json -Depth 5

Invoke-RestMethod http://localhost:8000/v1/chat/completions -Method Post -Body $body -ContentType "application/json"
```

### 3.3 PulseLive 项目配置

项目根目录 `.env` 中使用以下配置：

```env
PULSELIVE_LLM_BASE_URL=http://localhost:8000/v1
PULSELIVE_LLM_MODEL=Qwen1.5-1.8B
PULSELIVE_LLM_API_KEY=
PULSELIVE_LLM_TIMEOUT=60
```

由于 vLLM 占用 `8000` 端口，直播视觉审核服务改用 `8300`：

```env
GUARD_ENDPOINT=http://localhost:8300/check
PULSELIVE_GUARD_PORT=8300
```

启动项目 AI Agent 后，可访问：

```text
http://localhost:8100/api/agent/health
```

健康检查中 `llm.status` 为 `ok` 且 `configured_model` 为 `Qwen1.5-1.8B`，说明项目已经接入本地 vLLM 大模型。

### 3.4 答辩后删除本地大模型

如果答辩结束后要释放空间，在 WSL2 中执行：

```bash
pkill -f "vllm serve"
rm -rf ~/llm-deploy/models/Qwen1.5-1.8B
rm -rf ~/llm-deploy/myenv
```

如果整个 `~/llm-deploy` 目录只用于本课程项目，也可以直接删除：

```bash
rm -rf ~/llm-deploy
```
