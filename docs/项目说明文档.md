# PulseLive 项目说明文档

## 1. 项目定位

PulseLive 是一个面向课程作业和答辩展示的直播平台项目。项目包含前台用户端、主播开播端、管理员后台和 AI 辅助服务，目标是模拟一个具备基础商业直播平台能力的系统。

## 2. 技术栈

### 2.1 前端

- Vue 3
- Vite
- Ant Design Vue
- Pinia
- Vue Router
- flv.js / hls.js
- WebRTC / WebSocket

### 2.2 后端

- Spring Boot
- Spring Security
- MyBatis-Plus
- MySQL
- Redis
- Netty WebSocket
- MinIO / 文件上传
- 支付宝沙箱
- 邮件 / 短信服务

### 2.3 AI 与本地服务

- 小脉 AI 助手服务
- DeepFilterNet3 实时降噪服务
- Live Guard 视觉内容审核服务
- 本地直播媒体服务
- 管理员演示模式开关
- 答辩启动脚本

## 3. 系统角色

### 3.1 普通用户

- 浏览直播
- 搜索直播间
- 进入直播间观看
- 发送弹幕
- 送礼
- 关注主播
- 查看历史
- 充值与查看账单
- 举报直播间
- 联系客服
- 使用小脉 AI 助手

### 3.2 主播

- 完善个人信息
- 创建和维护直播间信息
- 使用网页开播工作台
- 开启屏幕直播或摄像头直播
- 使用实时降噪、互动助手和直播状态看板

### 3.3 管理员

- 管理用户
- 管理直播间
- 处理举报
- 处理客服工单
- 维护分类、礼物、菜单、角色、字典和系统配置
- 查看后台统计数据

## 4. 核心业务流程

### 4.1 观看直播流程

用户进入首页，选择直播间后进入观看页。直播间提供播放器、弹幕、礼物、关注、举报、守护等能力，同时写入观看历史和用户行为数据。

### 4.2 主播开播流程

主播进入个人中心或开播入口，完成直播间准备后进入开播工作台。工作台中选择屏幕直播或摄像头直播，通过唯一的开始按钮启动直播。直播中可查看预览、降噪状态、互动信息和直播状态。

### 4.3 内容安全流程

直播过程会进行内容风险检测。风险内容可进入管理员审核流程；用户也可以在直播间主动举报，管理员在后台进行处理。

### 4.4 客服流程

用户在个人中心提交客服工单，管理员在后台处理并回复，用户侧可以查看处理状态和回复结果。

### 4.5 AI 辅助流程

用户可以使用小脉 AI 助手咨询平台功能。小脉会携带当前页面、登录状态和页面可执行操作作为上下文，给出更贴近当前场景的建议。直播间还保留内容风险识别、弹幕氛围分析和推荐算法，体现 AI 能力与平台治理、互动运营的结合。

## 6. 答辩启动命令

```powershell
# 启动前端、后端和 AI Agent
.\scripts\start-demo.ps1

# 停止演示进程
.\scripts\stop-demo.ps1
```

演示直播间不再需要额外跑脚本。服务启动后，用管理员账号进入 `系统后台 -> 控制台`，打开“演示模式”开关即可启动多直播间录播演示；关闭开关后只会下线带演示标记的直播间，不影响真实主播。

## 7. 演示账号与数据

后台控制台的“演示模式”开关会自动补充多间录播直播间，并让这些房间保持在线。演示房间使用本地 MP4 录播素材，适合答辩时展示首页在线直播、分类筛选、搜索、进入直播间、聊天室、礼物和推荐等能力。

| 角色 | 账号 | 密码 | 适合展示 |
|---|---|---|---|
| 普通观众 | `demo_viewer_01` | `123123` | 首页、直播间、关注、消息中心、客服工单、钱包账单 |
| 演示主播 | `demo_anchor_01` | `123123` | 个人中心、直播数据、礼物流水、粉丝守护、开播工作台 |
| 管理员 | `demo_admin` | `123123` | 管理后台、演示模式开关、举报审核、客服处理、账单管理 |

演示模式的本地素材位于：

```text
frontend/public/demo-videos/
frontend/public/demo-covers/
```

答辩结束后如果想释放空间，可以删除这两个目录。数据库中的演示房间带有 `PULSELIVE_DEMO_ROOM` 标记，平时直接在后台关闭“演示模式”即可让它们下线。


## 8. 推荐演示路线

1. 打开首页，展示直播推荐、搜索和主题界面。
2. 进入直播间，展示播放器、弹幕、礼物、关注、举报。
3. 打开小脉 AI 助手，提问“当前页能做什么”，展示页面上下文感知。
4. 进入开播工作台，展示屏幕/摄像头开播、降噪、互动助手和直播状态。
5. 提交一次举报或客服工单。
6. 切换管理员后台，展示举报处理、客服处理、房间管理和用户管理。
7. 展示个人中心中的数据、钱包、账单和资料管理。

## 9. 课程作业总结

本项目不是单一页面 Demo，而是一个包含实时通信、媒体开播、AI 辅助、内容审核、用户体系、资产体系和后台管理的综合型直播平台。它适合从“业务完整度”“技术复杂度”“AI 接入”“实时互动”“管理闭环”五个角度进行答辩说明。
