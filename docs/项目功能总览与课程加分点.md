# PulseLive 项目功能总览与课程加分点

## 1. 项目简介

PulseLive 是一个直播平台课程项目，覆盖用户端观看、主播端开播、管理员审核和 AI 辅助能力，形成了从“看直播、开直播、管直播”到“审核、客服、数据、消息”的完整闭环。

## 2. 功能总览

### 2.1 用户端

- 首页推荐和分区浏览
- 搜索主播、房间标题、分区
- 直播间观看、弹幕互动、礼物发送
- 关注主播、查看观看历史
- 私信聊天、消息通知
- 钱包、充值、账单查看
- 举报直播间内容
- 联系客服并提交工单

### 2.2 主播端

- 个人中心与资料编辑
- 实名认证
- 开播准备页
- 网页开播工作台
- 屏幕直播 / 摄像头直播切换
- 直播预览、停止直播
- 实时字幕
- 实时降噪
- 摄像头浮窗
- 字幕助手分析
- 直播数据看板
- 守护管理
- 收益结算、礼物流水

### 2.3 管理端

- 用户管理
- 直播间管理
- 认证审核
- 内容审核
- 举报处理
- 客服工单处理
- 礼物管理
- 分类管理
- 菜单管理
- 角色管理
- 字典管理
- 系统配置
- 系统消息
- 账单管理
- 数据总览

### 2.4 AI 与实时能力

- 小脉 AI 助手
- 直播字幕 AI 分析
- 直播内容风险识别
- 实时音频降噪
- 直播推荐
- WebSocket 实时互动
- WebRTC 网页开播链路

## 3. 课程作业加分点

| 加分点 | 体现方式 | 为什么加分 |
|---|---|---|
| AI 智能体接入 | `小脉 AI 助手`、`字幕助手`、直播页 AI 交互 | 不只是“接了一个聊天框”，而是把 AI 放进了直播业务流程里 |
| 实时开播能力 | 网页端直接开播、屏幕/摄像头切换、预览、停止 | 体现 WebRTC 和实时媒体链路，不是静态展示页 |
| 实时降噪 | 主播开播时可启用降噪 | 有实际业务价值，能体现音频处理能力 |
| 内容安全 | 直播风险检测、举报、管理员处理 | 有完整治理闭环，不只是能播不能管 |
| 直播运营闭环 | 关注、历史、礼物、钱包、账单、守护、数据看板 | 业务链条完整，符合“平台型项目”要求 |
| 后台管理体系 | 用户、房间、分类、礼物、角色、配置、消息管理 | 体现前台 + 后台的一体化设计 |
| 实时通信 | 弹幕、通知、私信、开播信令 | 说明项目不是纯页面拼装，而是有实时交互能力 |
| 主题化 UI | 统一的个人中心、直播间、管理后台风格 | 展示项目完成度和商业化感，更适合答辩展示 |

## 4. 答辩建议重点讲的 4 个点

1. AI 智能体不是摆设，而是嵌入直播字幕和主播辅助场景。
2. 开播链路是完整的，包含预览、推流、切换模式、停止、实时状态。
3. 平台有内容安全和人工处理机制，不是单纯“播出去就完了”。
4. 用户、主播、管理员三类角色都能找到对应功能，项目闭环完整。
